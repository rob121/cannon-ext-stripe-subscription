Setup Checklist

Configure Stripe keys, create products with Price IDs, then wire public routes including /webhooks/stripe.

  1. 1
    Configure API keys

    Open Stripe Settings and enter test/live keys plus the webhook signing secret.

  2. 2
    Add a product

    Create at least one product with a Stripe Price ID (price_…).

  3. 3
    Create site routes

    Add routes for product, account, return, checkout, portal, cancel, and webhook (see extension help).

  4. 4
    Point Stripe at the webhook

    In Stripe Dashboard, send events to https://yoursite/webhooks/stripe.
